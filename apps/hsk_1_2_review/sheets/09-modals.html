Sheet 09 · Tier 1

Modal verbs: 想 / 要 / 会 / 能

~25 min
Reference
Quick reminder

All four sit in the same slot: S + [modal] + V …. They're negated with 不 (not 没) and can ask questions either with 吗 or by using the "A-not-A" form 想不想 / 要不要 / 会不会 / 能不能.

ModalMeaningNegative
想would like to / want to (wish)不想
要want / going to / must (stronger intent)不想 (不要 = "don't!")
会can (learned skill) / will (future/likely)不会
能can (capability in situation / permission)不能

Rule of thumb: 会 = "I've learned how"; 能 = "I'm able/allowed right now".

Warm-up recall

  1. Translate: I'd like to drink tea.
  2. Translate: I'm going to travel to Beijing.
  3. Translate: I can speak Chinese.
  4. Translate: May I sit here?

Structured practice

  1. Fill in 想 / 要 / 会 / 能:
    (a) 明天 下雨。 (b) 我的腿疼，我不 走。 (c) 你 不 跟我一起去? (d) 我 买一件新衣服。 (e) 他 说四种语言。
  2. Fix: 我没想去。
  3. Fix: 他说汉语很好。 (intended: "He can speak Chinese well.")
  4. Translate: I can't go today because I have a meeting.
  5. Translate: Can you swim? — and — Are you able to come tomorrow? (different modals!)
  6. Translate: Don't smoke here. (the "don't" flavour of 要)
  7. Translate: It'll probably snow tomorrow.
  8. Question in "A-not-A" form: 他想去。 → ?
  9. Translate: If Xiǎo Wáng wants to go, I don't feel like going.
  10. Mini-dialogue:
    — Can you speak English?
    — A little. But I can't write English.
    — No problem. I want to learn Chinese.

Warm-up

  1. 我想喝茶。
  2. 我要去北京旅游。
  3. 我会说汉语。
  4. 我能坐这儿吗?

Structured

  1. (a) 会 (b) 能 (c) 想…想 (d) 想/要 (e) 会
  2. 我不想去。 — modals take 不, not 没.
  3. 他汉语说得很好。 — ability-with-quality is expressed with the 得 complement (sheet 17), not the modal 会.
  4. 我今天不能去，因为我有会。
  5. 你会游泳吗? · 你明天能来吗?
  6. 不要在这儿抽烟。 / more idiomatic: 别在这儿抽烟。
  7. 明天会下雪(的)。
  8. 他想不想去?
  9. 小王要去，我不想去。
  10. 你会说英语吗? — 会一点儿。不过我不会写。— 没关系。我想学汉语。
