Lesson 13

我是走回来的

Wǒ shì zǒu huílai de

I walked back (that's how I got here)

What you'll learn

  1. 把字句 3 — the full 把 frame with result or direction complements. This fuses Lessons 10, 11, 12 into one system.
  2. 先 … 再/又 … 然后 … — sequencing multiple steps in order.

1. 把字句 3: A 把 B + V + result/direction complement Disposal + what became of B

When a speaker reaches for this: when they want to say how the object ended up after the action — not just "where" (L11) or "done" (L10), but in what shape. Did you finish writing it (写完)? Did you cook it and have it ready (做好)? Did you bring it back (拿回来)? The 把 frame is where Chinese collects "what happened + what state it's in now".

The cognitive picture — 把 as the full disposal story

Lessons 10-12 were not separate tricks. They were the same 把 engine with different endings:

  • L10: 把 + B + V + 了 → "grab B, do V, done." 我把门关了.
  • L11: 把 + B + V + 在/到 + place → "grab B, move it, and it ended up here." 我把书放在桌子上.
  • L12: 把 + B + V + direction → "grab B, move it, and it ended up toward/away from me." 把水果拿过来.
  • This lesson: 把 + B + V + result or direction → "grab B, do V, and this is the state now." 我把作业写完了 (writing → finished). 他把礼物拿回来了 (taking → brought back here).

Temporal sequence again: grab → act → result/arrival. The sentence walks through the event in order.

The English trap

English fuses result into the verb ("I finished writing", "I brought it back"). Chinese keeps them separate — a plain action verb (写, 拿, 买) plus a complement that declares the outcome (完, 好, 回来, 出去). Your English brain will try to pack it all into one word; resist. Pick the action, then pick the result.

The 把 frame shown as a full timeline. Each slot is one beat of the event.
A + 把 + B + V + result / direction (+ 了 )

Slow parse: result vs direction

我把作业写完了。

  • 我 = actor; 把作业 = the known object we care about.
  • 写 = action; 完 = result, finished; 了 = the result is complete.

请把礼物拿出来。

  • 请 = request; 把礼物 = the known object.
  • 拿 = action; 出来 = direction/result, out toward the speaker.

Same 把 frame, different ending: one says what state the object reached; the other says where it moved relative to the speaker.

With a result complement

我把作业写完了。

Wǒ bǎ zuòyè xiě wán le.

I / [disposal] / homework / write / finish / PERF

I finished the homework.

他把饭做好了。

Tā bǎ fàn zuò hǎo le.

he / [disposal] / meal / make / to-good / PERF

He got the meal ready.

我真怕他累坏了。

Wǒ zhēn pà tā lèi huài le.

I / really / fear / he / tired / to-broken / PERF

I'm really afraid he'll wear himself out. (累坏 = "tired-to-broken", a resultative pair even without 把 — the object is implicit "himself".)

With a direction complement

Now fold in Lesson 12's compound directionals. Notice: the speaker's orientation (来/去) is still part of the result — it says where B ended up relative to me.

哥哥买回一个西瓜来了。

Gēge mǎi huí yí ge xīguā lai le.

elder-brother / buy / back / one / M / watermelon / come / PERF

Older brother bought a watermelon and brought it home. (No 把 here — B is indefinite "a watermelon", so plain V + direction works.)

请把礼物拿出来。

Qǐng bǎ lǐwù ná chūlai.

please / [disposal] / gift / take / out-come

Please take the gift out (so I can see it).

明天我们一起把礼物送过去。

Míngtiān wǒmen yìqǐ bǎ lǐwù sòng guòqu.

tomorrow / we / together / [disposal] / gift / deliver / across-go

Tomorrow we'll take the gift over (to them) together.

Definite vs indefinite B

Use 把 when B is specific and known (the gift, the computer, the homework). When B is a brand-new indefinite ("a watermelon", "some gifts"), you can skip 把 and put B between the stem and 来/去: 哥哥买回一个西瓜来. Rule of thumb: if English would use "the" — reach for 把. If it would use "a" — plain V + direction is fine.

定 (the) → use 把
他把西瓜买回来了
He brought the watermelon back (the one we discussed).
不定 (a) → skip 把
他买回一个西瓜来
He bought a watermelon and brought it home (news).

Practice

What's the end state in 他把礼物送过去了?

  • He's about to deliver the gift.✗ 了 + 过去 = completed action; the gift has already arrived.
  • The gift is now with the recipient (away from the speaker).✓ 送 + 过去 + 了 traces: grabbed gift → delivered → away from me → done.
  • He is bringing the gift toward the speaker.✗ That would be 送过来. 过去 = away from speaker.

Build: "I brought the red wine back."

我 把 红酒 带 回来 了

Which sentence is natural for "She finished reading the book"?

  • 她把书看完了。✓ Specific book + result complement 完 → 把 frame.
  • 她看完书了。✗ Grammatical but weaker — without 把, the focus drifts off the book's end state. Native speakers prefer 把 here.
  • 她把书完看了。✗ Complement must follow the verb. 完 sits after 看, not before.

Fill the blank: 我把作业写___
(I finished the homework.)

完了 — 写完 = "write-to-finished"; 了 marks it as actually done.

Build: "He got the meal ready."

"Older brother bought a watermelon (and brought it home)." Which is most natural?

  • 哥哥买回一个西瓜来。✓ Indefinite "a watermelon" → skip 把; the object sits between 回 and 来.
  • 哥哥把一个西瓜买回来了。✗ 把 wants a definite object. 一个西瓜 is brand-new info — don't use 把.
  • 哥哥买来回一个西瓜。✗ 来/去 must follow the directional morpheme 回, not precede it. Order is V + 回 + (obj) + 来.

2. 先 … 再/又 … 然后 … Sequencing steps in order

When a speaker reaches for this: to lay out a sequence — "first this, then that, then the other". Directions, routines, plans, recipes.

The English trap

English lists with "first… then… after that…". Chinese uses a trio: 先 (first) — 再 or 又 (next) — 然后 (after that). They don't replace verbs; they sit before each verb like signposts on a timeline.

再 vs 又 here: 再 = next step still to come (future), 又 = next step already happened (past). Use 再 for plans, 又 for narration.

先 + V₁ , 再 / 又 + V₂ , 然后 + V₃

我先写作业，再吃饭，然后看电视。

Wǒ xiān xiě zuòyè, zài chī fàn, ránhòu kàn diànshì.

I'll do my homework first, then eat, and after that watch TV.

他先去了商店，又去了书店，然后回家了。

Tā xiān qù le shāngdiàn, yòu qù le shūdiàn, ránhòu huí jiā le.

He went to the shop first, then to the bookstore, and after that went home. (All past — 又 not 再.)

plan (future) — 再
我先吃饭，再休息
I'll eat first, then rest. (Still to come.)
narration (past) — 又
我先吃了饭，又休息了
I ate first, then rested. (Already done.)

Mini timeline: 再 vs 又

Both can mean "then", but they live on different sides of the timeline:

  • Plan still ahead: now → 先买菜 → 再做饭 → 然后吃饭. Use 再 because the next step has not happened yet.
  • Story already happened: 先去了商店 → 又去了书店 → 然后回家了. Use 又 because the speaker is adding another completed action.

If the sentence has tomorrow / later / plan language, expect 再. If it narrates completed actions with 了, expect 又.

Practice

You're describing tomorrow's plan: "I'll buy groceries first, then cook, then eat." Fill the middle slot:

  • 我先买菜，再做饭，然后吃饭。✓ Future plan → 再.
  • 我先买菜，又做饭，然后吃饭。✗ 又 marks a past sequence; this is a plan.
  • 我先买菜，然后做饭，再吃饭。✗ The order is 先 → 再/又 → 然后, not 先 → 然后 → 再.

Build: "I'll exercise first, then eat, then sleep."

What does this sentence tell us?
他先去了商店，又去了书店。

  • He will go to the shop, then to the bookstore.✗ 又 + 了 = past. For future plans you'd say 先…再… .
  • He already went to the shop, and then to the bookstore.✓ 又 narrates a completed sequence; 了 confirms both actions finished.
  • He goes to the shop every time before the bookstore.✗ That would be a habit — you'd use 先…再… or 每次…都… .
