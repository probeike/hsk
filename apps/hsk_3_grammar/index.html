20 Interactive Grammar Lessons

A first-pass grammar walkthrough for English speakers — built to make each structure intelligible before you practise it in the HSK book.

How these lessons are built

Each lesson takes one HSK 3 chapter and teaches its grammar from first exposure to practice. The explanations are built around five principles drawn from research on Chinese second-language acquisition:

  1. Function first — when a speaker reaches for this structure, before any rules about form.
  2. The English trap — the specific English-speaker instinct that misleads on this structure, named out loud.
  3. Image schemas — a reusable mental picture for markers like 把, 被, 着, 了, 会. The same icon reappears whenever that marker does.
  4. Contrastive minimal pairs — one sentence with / without the structure, or one word-order vs another, with the meaning delta spelled out.
  5. Processing-instruction tasks — for the passive (被) and disposal (把), exercises that force you to decode the marker to get meaning right, training you past the "first noun = doer" instinct.

All pages work offline — no CDN, no fonts from the web. Read the walkthrough first, then use your HSK book exercises for practice.

Suggested path

The lessons build on each other. If you only have time for the hardest material, the three lessons English speakers struggle with most are L10 (把字句), L12 (compound directionals), and L19 (被字句). These rewire word order most, and each gets extra pedagogical scaffolding — schema diagrams, interpretation tasks, and minimal-pair contrasts.
