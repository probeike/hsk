# Conjunctions: 和 · 因为…所以 · 虽然…但是 · 也 · 还

**和 = "and" for NOUNS only**. Don't use 和 to glue verbs, sentences, or clauses.

我和哥哥都在北京。 ✓    我吃饭和看电视。 ✗

**因为…所以…** — Chinese loves to keep both halves in place, unlike English which usually drops one. If the order is effect → cause, a common alternative is "A, 因为 B" with the 所以 dropped.

**虽然…但是…** — also frequently "double-marked". The 但是 can upgrade to 可是 / 不过 for a softer tone.

**也 ("also") / 还 ("also, in addition")** — both are pre-verbal adverbs.

- 也 echoes the subject or predicate from the previous clause ("me too / I also do X").

- 还 adds another thing of the same kind: "and also…".

Neither 也 nor 还 can start a sentence the way English "also" and "and" can.
