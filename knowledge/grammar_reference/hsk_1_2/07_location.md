# Location: 在 (verb & preposition) · 有 (existential)

**在 as a verb**: tells you where something already-known is.

S + 在 + Place

**在 as a preposition**: locates an action.

S + 在 + Place + V (+ O)

Remember: the 在 Place goes *before* the verb. English: "I work at a hospital." Chinese: 我在医院工作。

**Existential 有**: given a place, tells you what's there.

Place + 有 + Thing · negative: 没有

**在 vs 是 vs 有** triangle:

- Subject is a known thing, you want to locate it → 在.

- Subject is a place, you want to describe what's there → 有.

- Subject is a place, you want to identify a specific thing there → 是.

**Localisers** stick on the end of a noun: 桌子上 / 床下 / 房间里 / 学校旁边 / 银行前面 / 医院后面.
